# NNN. ここに一行で題名

- 状態: 未決
- 起票日: YYYY-MM-DD
- 関連: 判断の対象になるファイルやコマンド
- 暫定実装: なし（置いた場合は「あり — path:line にどう置いたか」）

## 何に迷ったか

何を決めかねているのか。なぜ自明に決まらないのかまで書く。
「どちらでもよい」ものは判断ではないので、提案にしない。

## 選択肢

| 案 | 内容 | 利点 | 欠点 |
|---|---|---|---|
| A | | | |
| B | | | |

見え方が争点なら、実際の出力例を並べる。文章より速く伝わる。

```
案A の出力例
```

```
案B の出力例
```

## 推奨案とその理由

どれを推すか。理由は「読み手にとって何が良くなるか」で書く。
推奨できない場合は、何が分かれば決められるのかを書く。

## 保留による影響範囲

決めないまま進むと何が起きるか。

- 影響を受けるファイル / コマンド
- 今どう振る舞っているか（暫定実装があればその挙動）
- 後から変える場合の手戻りの大きさ
- 他の判断がこれに依存しているか
