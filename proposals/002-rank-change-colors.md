# 002. 変動の配色

- 状態: 未決
- 起票日: 2026-08-22
- 関連: `scripts/build_site.py` の `STYLESHEET` / `delta_kind()`
- 暫定実装: あり — 色を一切使わない案A相当。符号と語だけで方向が分かる状態になっている
- プレビュー: `python scripts/build_previews.py` を実行後、`site/previews/index.html` から

## 何に迷ったか

一覧の変動列は現在、色を使わずに `+9` `-6` `=` `初` `再` `—` だけで表している。
方向は符号で読めるので情報としては足りている（DP-2.4）。

ただし100行を走査する画面では、**色があると上昇と下降の塊が一目で掴める**。
色を足すこと自体は妥当だが、どの対を選ぶかで2つの基準がぶつかる。

- **地域の慣習**（DP-5.2）… 日本では上昇＝赤が標準。西洋式の上昇＝緑は直感と逆になる
- **色覚特性**（DP-7.4）… 赤と緑の対は最も区別しにくい組み合わせ

赤緑を採ると慣習には沿うが区別しにくい。緑赤なら慣習に反し、しかも同じく区別しにくい。
この2軸が独立でないため、好みでは決められない。

なお本日時点のデータでは上昇30件・下降34件・変動なし36件・ランク外2件で、
**初登場と再登場は0件**。プレビューではその2つの見え方は確認できない（どの案でも色は付けていない）。

## 選択肢

| 案 | 内容 | 利点 | 欠点 |
|---|---|---|---|
| A | 色を使わない（現状） | どの環境でも同じに読める。色を他の用途に温存できる | 100行の走査で上昇・下降の塊が掴めない |
| B | 上昇＝赤 / 下降＝青 | 日本の慣習に沿い、色相が離れていて明度差も付く | 青がリンク色と近く、可読の文脈がわずかに競合する |
| C | 上昇＝赤 / 下降＝緑 | 日本の慣習に沿う。相場表示として最も見慣れた対 | 最も多い色覚特性で区別できない |
| D | 上昇＝緑 / 下降＝赤 | 海外のサービスに慣れた読み手には自然 | 日本の慣習と逆。かつ区別しにくい対 |

いずれの案でも符号と語は残すため、色が読めなくても情報は失われない。

## 推奨案とその理由

**案B（上昇＝赤 / 下降＝青）を推す。**

日本のチャートを日本語で見せる以上、上昇＝赤の慣習に合わせるのが読み手にとって自然。
そのうえで下降を青にすれば、**赤緑の対を避けられる**。色相が大きく離れ、明度差も自然に付くため、
色の見え方に関わらず2つの塊を区別できる。慣習と可読性が両立する唯一の案という位置づけ。

案Cは見慣れた対だが、区別できない読み手を最初から切り捨てることになる。
案Dはその欠点を持ったうえに慣習にも反するため、日本語のサイトで採る理由が乏しい。

案Aを続ける判断もあり得る。色を使わなければ、後から**別の用途**（初登場の強調など）に
色を回せる。ただし今回の一覧は走査が主目的なので、変動に色を使う価値のほうが高いと考える。

青がリンク色と近い点は、リンクの側に下線を残すことで区別できる。

## 保留による影響範囲

決めないままでも壊れるものは無い。案A相当の状態が続くだけ。

- 影響するのは `build_site.py` の `STYLESHEET` のみ。**マークアップの変更は不要**で、
  変動セルは既に `data-kind` を持っているため、CSSを数行足すだけで切り替わる
- **003（情報密度）の判断がこれに依存する。** 色があると行を詰めても塊が掴めるため、
  詰めた密度を選びやすくなる。色が無いままなら、走査の負担を行間で補う必要がある
- 004（狭い画面での畳み方）にも軽く影響する。1曲1ブロックに積み上げる案では、
  変動が縦に並ばないため色の効き方が変わる
- 後から変えるのは容易。データにも集計にも波及しない
- 決めた対は、後で個別曲ページ（P8）や週次メール（P9）でも同じ意味で使うことになる。
  ここで決めた色が事実上の基準になる
